LLM · RAGCode ↗

Grounded RAG Service with Guardrails

A question-answering API over a document collection that only answers from what it can cite.

  • Every answer carries chunk-level citations, checked against the retrieved text.
  • Declines before calling the LLM when nothing relevant is found, and resists prompt injection.
  • Tracks cost, tokens and latency per request across GPT-4o, GPT-4o-mini and o3-mini.
  • Re-ingestion is safe to repeat; ships with health checks, smoke tests and a simple UI.

Agents · MCP · A2ACode ↗

Multi-Agent Customer Support System

A support assistant where a router agent hands each request to the right specialist.

  • Billing, technical and shipping specialists, coordinated by one router agent.
  • The billing agent reads a live Supabase database through an MCP server.
  • The shipping agent runs as its own service and is called over the A2A protocol.
  • Every run is traced in Langfuse for debugging and monitoring.

Forecasting · EU projectCode ↗

Next-Day Energy Consumption Forecasting

Predicting tomorrow's household energy use from smart meter data for the MASTERPIECE project.

  • Compared LSTM, GRU, CNN-LSTM, LightGBM and Random Forest models.
  • Worked with 15- and 60-minute meter readings and lookback windows from 24 hours to 7 days.
  • Engineered time-based and lag features; evaluated with MSE and quantile loss.
